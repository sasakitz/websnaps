WebSnaps プライバシーポリシー

WebSnaps は、ユーザーが指示したWebページの撮影・編集・保存を端末内で行います。画像には個人情報が写ることがありますが、拡張機能が画像や閲覧情報を開発者・外部サーバーへ送信することはありません。

対象と提供者

本ポリシーは、sasakitz が提供する Chrome 拡張機能 WebSnaps に適用されます。お問い合わせ先は GitHub Issues です。

取り扱う情報と利用目的

情報用途・保存場所外部送信
撮影画像・選択範囲・ページ寸法・スクロール位置ユーザーが開始した撮影、画像の結合・切り抜き・編集に使用。元の撮影画像と撮影用メタデータは拡張機能のIndexedDBに一時保存。編集中の画像と編集履歴はメモリ内で処理。なし
ページ上の要素の位置・大きさ・表示スタイル、選択時のマウス・キー操作要素選択、範囲調整、ページ全体の撮影・撮影後の表示復元に使用。メモリ内のみ。なし
タブのID、URL等のタブ情報撮影対象・制限ページの判定と、開いている編集タブの特定・一時画像の削除に使用。起動時の編集タブ検出では開いているタブのURLを参照。閲覧履歴のデータベースは作成せず、URLを設定や画像データに保存しません。エラー時には対象URLが端末内の開発者コンソールに表示される場合があります。なし
保存形式の設定（PNG / JPG）、撮影開始時の形式設定chrome.storage.localのformat / pendingFormatに保存。次回起動時の形式の引き継ぎなどに使用。なし

撮影対象の画面には、氏名・メール、個人的な通信、認証情報、健康情報、支払い情報などが含まれる可能性があります。これらも画像の一部として端末内で処理されます。種類別の抽出、利用者のプロファイリング、広告利用は行いません。共有前に画像の内容をご確認ください。

要求する権限

  • activeTab: ポップアップ起動やショートカットなど、ユーザーの操作を起点にアクティブなタブを撮影・操作するため。
  • scripting: 選択UIの挿入、要素の位置・サイズ取得、自動スクロールと撮影中の表示調整・復元のため。
  • clipboardWrite: 「コピー」を押した画像をクリップボードへ書き込むため。
  • storage: 保存形式の設定を端末内に保持するため。
  • tabs: 撮影対象URLや開いている編集タブのURLを確認し、一時データを適切に削除するため。
  • <all_urls>: ユーザーが撮影を指示したページに選択UIや撮影用スクリプトを挿入し、表示範囲を撮影するため。常駐コンテンツスクリプトによる自動収集は行いません。ブラウザが制限するページには利用できません。

第三者への提供とデータ利用

拡張機能から開発者または第三者へのデータ送信・販売・共有は行いません。広告、アクセス解析、追跡用SDK、遠隔コード、ログイン機能は含まれません。ユーザーデータを撮影・編集・保存という目的以外に利用せず、信用力の判定や融資目的にも利用しません。

ユーザーが「画像を保存」「コピー」を選ぶと、画像がダウンロード先またはOSのクリップボードに出力されます。その後の貼り付け・共有先はユーザーが選択します。GitHub等のサポートサイトを利用する場合、そのサイトのポリシーが別途適用されます。

保存期間と削除

元の撮影画像は編集中の再読み込みにも使います。編集タブを閉じると対応する一時画像を削除します。異常終了などで残った不要な画像は、次回サービスワーカー起動時に開いている編集タブと照合して削除します。編集履歴はタブを閉じると失われ、再読み込みでは元の撮影画像が表示されます。

保存形式は変更または拡張機能のアンインストールまで端末内に保持します。アンインストールすると拡張機能内の設定と一時画像は削除されます。ダウンロード済みの画像やOSのクリップボード・クリップボード履歴は対象外です。これらは端末の機能で別途削除してください。

安全な利用とお問い合わせ

端末内のデータ保護は、ChromeとOSのアクセス制御を利用します。機密情報を含む画面の撮影・共有にはご注意ください。ぼかし・モザイクは画像加工機能であり、共有前の内容確認が必要です。

お問い合わせは GitHub Issues へお寄せください。公開の場には、個人情報や機密画像を投稿しないでください。本ポリシーを改定する場合はこのページの更新日を変更します。

English summary

WebSnaps, provided by sasakitz, captures and edits web pages locally when you request it. It handles screenshots, selection geometry, page layout, selection input and tab information (including URLs). Screenshots may contain personal or sensitive information. These data are used only to provide capture, editing and export, and are not transmitted to the developer or third parties, sold, used for advertising, unrelated purposes, creditworthiness or lending.

Original captures and capture metadata are temporarily stored in the extension's IndexedDB for handoff and editor reload. They are deleted when the editor tab closes; orphaned records are removed on the next service-worker startup. In-memory edits are lost on reload. PNG/JPG preferences are stored in chrome.storage.local until changed or uninstalled. Tab URLs are read to identify capture targets and live editor tabs; they are not stored in a browsing-history database. Local error logs may show a target URL.

Saving or copying exports an image to your downloads or OS clipboard at your request. Uninstalling removes extension data, but not exported files or clipboard history. The extension has no analytics, ads, remote code or sign-in. Chrome and OS access controls protect local data. Contact: GitHub Issues. Do not post sensitive data in public issues. This page is updated when the policy changes.
