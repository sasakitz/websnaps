## ダッシュボードへの入力順

1. `dist/websnaps-1.1.0.zip` を新規アイテムまたは既存アイテムのパッケージとしてアップロード。**提出資料一式ZIPはアップロードしません**。
2. Store listing: `store-listing.md` の名前・説明・カテゴリ・言語・URLを入力。日本語をプライマリにし、必要なら英語の掲載文を追加（製品UIは日本語）。
3. 画像: `assets/store-icon-128.png`、`screenshots/01`〜`05` の5枚を順に入力。必要に応じて `promo/` の2枚を追加。動画は任意のため空欄。
4. Privacy practices: `review/privacy-practices.md` の単一目的、全6権限の理由、リモートコード「使用しない」、データ分類と宣誓、公開済みポリシーURLを入力。
5. Distribution: 価格・公開範囲・配信地域、その他本人情報を確認。
6. Test instructions: `review/reviewer-instructions.md` の英語ブロックを貼り付け。ログインが必要か聞かれた場合は「不要」。
7. 各タブに表示されるエラーと不足項目を解消し、プレビューで文言と画像順を確認。
8. 必要なら審査通過後の自動公開を無効にし、手動公開を選択。最終内容を確認して「審査に提出」。
9. 審査結果はダッシュボード・登録メールで確認。日数は保証されないため固定の審査完了日は設定しない。

## プライバシーポリシーの公開方法（GitHub Pagesを使う場合）

1. 更新した `store/privacy-policy.html` を公開リポジトリの公開対象ブランチに反映。
2. GitHubのSettings → Pagesで、利用する公開ブランチと `(root)` を選択。ブランチ名は実際の構成に合わせる。
3. 公開URL候補: `https://sasakitz.github.io/websnaps/store/privacy-policy.html`。
4. キャッシュに残った古いポリシーでないこと、画像の一時保存・削除とURL等の参照が説明されていることを確認。

GitHub Pagesの既存設定（mainブランチ / ルート）を使用し、プライバシーポリシーのみGitHub経由で更新・公開しました。CWS提出は未実施です。
